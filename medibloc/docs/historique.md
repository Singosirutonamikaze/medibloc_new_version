## Règle d'or pour les développeurs

Chaque développeur doit **impérativement** ajouter une ligne dans le tableau ci-dessous pour chaque commit ou tâche significative réalisée, avant de soumettre sa proposition de modification (Pull Request).

---

## Modèle d'entrée (Template)

Pour ajouter une ligne au tableau, utilisez le format Markdown suivant :

```markdown
| AAAA-MM-JJ | Nom Prenom | Description du travail réalisé | `hash_commit` |
```
